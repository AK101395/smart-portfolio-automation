SpendWise

Personal Finance Management Application

SpendWise is a modern personal finance application designed in Figma and planned for Flutter development. It helps users track expenses, manage budgets, monitor savings, and gain AI-powered financial insights.

Explore Project

Project Overview

SpendWise is a UI/UX project focused on creating a modern finance experience. The application is currently in the design phase using Figma and will later be implemented using Flutter and Firebase.

Key Features

💳 Expense Tracking

Record and organize daily expenses.

📊 Analytics

Interactive charts and financial insights.

🎯 Budget Planning

Create monthly budgets and monitor spending.

🤖 AI Insights

AI-inspired recommendations and spending analysis.
